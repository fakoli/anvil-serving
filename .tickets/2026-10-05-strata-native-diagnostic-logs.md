# Strata native phase diagnostics absent from managed logs

Status: implementation awaiting independent review and live verification.

The pinned server redirects the owning engine stderr to its internal log. Managed recipe logs expose startup narration and optionally request summaries, but omit numeric prefill phase timings needed to diagnose a measured latency gate failure. File-tier counters are mapped-file accesses, not proof of physical SSD reads.

Add a pinned derived artifact layer over the existing strict memory profile. Hash-check the exact upstream server before modifying its existing tail loop; export only reconstructed numeric timing records with bounded complete-line parsing. Separately hash-check the fixed prepared expert metadata and export numeric layout totals. Retain all prior image/build inputs unchanged. No arbitrary file-read API, prompt/reasoning logging, model downloads, or new runtime dependency.

Validation requires parser rejection/fragment/oversize tests, source identity refusal, exact metadata identity and shape checks, reviewed-launcher forwarding, independent review, then managed build/load/log evidence. Instrumented timing is diagnostic, not a replacement performance headline. Any fused-kernel experiment changes arithmetic and requires renewed quality gates.
