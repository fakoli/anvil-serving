## Implementation steps

1. Replace stacked plan/task tables with searchable selection, plan reader, task detail and contextual execution/evidence controls. Preserve stable project/plan/task URLs.
2. Show Run with Pi when eligible, with a preview of canonical packet, workspace, accessible roots, provider/model and lease implications. Show exact blockers otherwise.
3. Reuse existing claim/provision/start and idempotency machinery. Link the resulting session in Playground and run in Workbench using native IDs; Resume returns to an existing binding.
4. Retain stop, patch capture, digest-bound verification/transfer, submission and independent Anvil acceptance. Recover uncertain starts and failed verification without automatic second claims or hidden resubmission.

## Acceptance

- [ ] A consistent plan opens; choosing its ready task previews and starts exactly one isolated run with links in all three surfaces.
- [ ] Draft PRD, open dependencies, foreign claim, expired lease, unavailable storage/egress and duplicate start are distinguished and fail before unauthorized execution.
- [ ] An interrupted start resumes/reconciles the original binding; a foreign task session cannot be adopted.
- [ ] Evidence can be captured after stop, verified against frozen packet commands and submitted; acceptance remains pending independent review.
- [ ] A non-ready existing task is not mutated merely to demonstrate the UI; use a disposable approved fixture.
