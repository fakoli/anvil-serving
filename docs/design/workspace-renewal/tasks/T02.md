## Implementation steps

1. Record installed Pi Web/Pi versions and immutable package identities, license, API/transport routes and session ownership. Read current code/docs locally; verify upstream primary sources only for unresolved contracts.
2. Build a disposable development harness using synthetic sessions and fake model responses. Test one embedded Pi tab with existing owner authentication; do not alter the production service or consume live model capacity.
3. Test frame/CSP/edge rules, redirects, origin/CSRF checks, cookies, reconnect, assets and service workers. Specify whether cross-origin framing, a supported subpath build or a native RPC seam passes.
4. Prove host-session visibility is owner-scoped and managed task sessions retain their sandbox/lease. Inventory public Pi Web extension points for project context and multi-root support. Define an allowlisted versioned context handshake only if needed; validate message origin/source and never carry credentials or raw paths.
5. Write a decision receipt listing supported/unsupported features, exact source modifications if required, rollback and the selected implementation. Stop after one bounded spike per viable transport; do not fork the whole app by default.

Save the decision and independently reviewed receipt at the paths defined in
[VALIDATION.md](../VALIDATION.md#resume-rules). Required decision output:
`integration_decision.status = passed | blocked`, selected
transport, exact Pi versions, host authority label, task authority proof and
failed-case evidence. Only `passed` satisfies T03/T05 dependencies. Documenting a
fallback proposal or failed spike does not pass this gate.

## Acceptance

- [ ] A retained synthetic session opens inside Playground and survives navigation/reconnect without duplicate writers or transcript copying.
- [ ] A different principal, expired identity and forged context cannot read/control the session. Task sessions cannot gain host authority.
- [ ] Chat streaming and extension confirmation work inside Playground through the selected transport; apply frame/CSP/child-navigation checks to iframe options and API origin/CSRF/auth checks to native RPC. No blanket weakening, root service-worker collision or Workbench API shadowing.
- [ ] If reuse fails, document the exact blocker and bounded native-RPC alternative; a standalone link is not final acceptance.
