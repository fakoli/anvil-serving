Both 32-request finalist pairs are complete. At nominal 32K/C4 (about 25K observed prompt tokens), APC's unique-cache request throughput was 2.388% lower, within the 5% non-regression gate; shared-cache visible TTFT fell 67.84% and request throughput rose 3.1655x. The earlier eight-request scout remains a negative descriptive signal. The candidate also passed four eight-image cases, a 309,422-token needle, a 110,760-token tool call, and bounded diagnostic quality checks. These are not a SWE/coding-intelligence result. Baseline restoration and direct/authenticated routed acceptance are verified. No route or model promotion is authorized by this evidence.
