## Outcome and decision

The selected 32K BF16 Triton + MTP3 lane passed 27 functional checks, 8 thinking checks, 18/18 image attempts, 30/30 limited MMLU diagnostic attempts, and 100/100 strict capacity requests. The final managed state retained the exact pinned model/image, healthy HTTP status, and 32K served identity. Final telemetry recorded 3,342 MiB free. The prior Qwen was stopped; caches were retained. The selected candidate remains running under explicit user authorization, verified by [managed and HTTP ending-state checks](2026-09-23-thinkingcap-evidence/restoration.json). No route/client promotion occurred. Complete local weights comprise 26 files (23,447,947,228 bytes), including the BF16 vision tower and MTP weights.

## Method

Capacity uses 100 unique-cache, canary-controlled strict 32-word requests at nominal 4K/C1: actual inputs 3,609-3,687 tokens, 45 completion tokens per request, max output 512, thinking disabled. The serving process was warm, prefix caching disabled, and the first measured request retained. This uncontended population measures short controlled output, not general-chat speed. Context uses five deterministic cases, two requested-input buckets, three needle positions and two repetitions (60 observations), with model-default reasoning and a 2,048-token total completion cap. The configured maximum 32,768 is not a tested 32,768-token input. CPU documentation checks overlapped context and functional/quality tests, so their latencies are diagnostic only. Agentic smoke uses two cases, six API turns, and four tool calls. Functional and quality results are behavior evidence; the retained 32K capacity run is the timing population.

## Failures and caveats

Earlier eager and graph lanes remain retained comparison history. Earlier Flash-target MTP was 99/100 strict and is performance-ineligible. Triton + MTP3 FP8 passed function and capacity but failed the required quality gate 27/30 after three reasoning-budget exhaustions; it is rejected and its 56K lane was not run. The full repository gate retained one unrelated Windows Pi RPC failure: 7,923 passed, 417 skipped, one failed. The exploratory source patch was reverted; runtime and test code are unchanged. See [validation](2026-09-23-thinkingcap-evidence/validation-pi-failure.json) and [product gap](2026-09-23-thinkingcap-evidence/product-gaps/2026-09-23-windows-pi-rpc-validation.md).

The MMLU-Pro result is ten questions repeated three times at temperature zero, not a full benchmark score. No matched BF16-weight reference was tested. GPU telemetry sampled every five seconds; selected-profile minimum free memory was 3,342 MiB, below the initial 4 GiB reserve assumption, with sampled peaks of 478.03 W and 66 C. These samples include desktop/driver use and may miss peaks; there is no energy-per-token claim. See [telemetry](2026-09-23-thinkingcap-evidence/telemetry-summary.json).
