This is a public-safe selected-current evidence snapshot for the 2026-09-13 intelligence and
context campaign. It is an completed qualification snapshot. Raw native artifacts
remain private until a reviewed sanitizer removes endpoint, filesystem, and
device identifiers without changing score inputs, controls, failures, or
completion state.

## Publication boundary

The current manifest is a hashable incomplete ledger, not a completed artifact set. The dated finding is a draft and is intentionally not added to the finding
index, run catalog, model dossier, recipe catalog, or benchmark archive. Those
links may be added only after the campaign reaches a recorded decision and the
artifact manifest has been finalized twice with byte-identical output.
