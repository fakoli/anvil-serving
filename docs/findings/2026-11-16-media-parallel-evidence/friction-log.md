# Friction and limits

- An early observer HTTP503 interrupted sampling; the existing native jobs
  completed and were recovered by ID without another native submission.
- A safe worker quarantine during idle recycling led to a TIME_WAIT bind
  regression fixture and socket reuse fix. The earlier native errno was not
  captured, so that particular cause remains an inference; the fixture and
  later real recycling passed.
- Low free-commit headroom caused serial execution in superseded paired trials.
  Those decoded outputs are not counted as parallel passes. Final eligibility
  uses the unchanged 16 GiB floor plus 15 GiB per admitted image.
- A stale A2A transport fake, missing test-image process utility and missing
  explicit CLI confirmation contract failed successive regression attempts.
  Final full Linux suite passed; these failures were not erased.
- Windows full-suite collection has an unrelated UnixStreamServer platform
  issue. Focused Windows tests and full managed Linux tests passed.
- The final MCP harness initially waited for headroom before enqueueing, which
  prevented the real pool from recycling idle caches. No jobs were submitted;
  the harness was corrected to let production admission decide.
- Public model identity/native artifacts and a pre-execution common public
  plan are absent. This projection supports the bounded engineering account,
  not independent reproduction, quality ranking or statistical speed claims.
