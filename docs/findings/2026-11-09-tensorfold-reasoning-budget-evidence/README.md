# TensorFold reasoning-control evidence

This focused quality investigation changes request-local Max/Low effort on one
Go task while retaining the 16,384-token response cap, sampling, oracle and
per-job bounds. It separates source/template semantics, independent coding
grades and a proposed Anvil request-control patch. The proposal is not
deployed or an experimental arm here.

The retained `jobs/` trees keep native result schemas, request events, adapter
summaries and independent task-grade records. `inputs/` and `inputs-v2/` retain
the frozen order and pre-request custody amendment, pinned profile, source and
specifications. `qualification/loaded-template-summary.json` is metadata-only
verification of distinct Low/High/Max prompt instructions, using a dummy prompt.
`request-path-audit.json` records source findings and commitments to the full
private audit. `configuration.json` separates configured defaults from requested
controls and marks today's process/cache/memory baseline as different from the
earlier historical check.

`projection-ledger.json` records original private and published hashes/byte
counts, exact byte-preserving copies and each changed JSON leaf. Private paths,
host/GPU/process identity and the deployed router port are masked; process text
is omitted rather than publishing model prose. Native references inside a
projection still bind the original private bytes. They are not silently
rewritten to imply a complete public custody graph. Exact source and contained
oracle verification remain with the operator; no upstream codebase is vendored.

Owned jobs coexist with user traffic under the existing C4 policy. Before each
submission the declared gate is zero waiting and at most two running requests;
complete successful request accounting and worker exit gate the next owned job.
Global idle, exclusive engine counters and managed-campaign activation custody
are not claimed. Cache policy is preserved and its warm state uncontrolled.

Transport-call count is not coding-attempt count. Auxiliary calls are retained
without inventing a second grade. Native Aider usage/context labels are source
data; complete request observations and independent contained test results are
interpreted separately. Visible-token counts remain unknown, and subtraction
of reasoning from completion is only derived non-reasoning output.

The frozen quartet is complete: Low passed 2/2 first attempts, while Max
resolved 0/2 after response-cap starvation. The conditional temperature jobs
were unnecessary and were not run; temperature effects remain unmeasured.
