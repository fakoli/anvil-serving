# Evidence manifest: media gateway live validation

This directory contains the bounded, sanitized public record for the exact
merged media-gateway live validation performed on 2026-08-28.

## Files

- [live-validation.json](live-validation.json) — machine-readable source,
  protocol, artifact, quality, negative-control, restoration, and caveat data.
- [publication-summary.md](publication-summary.md) — derivative compact copy
  and claim ledger.
- [Dated finding](../2026-08-28-media-gateway-live-validation.md) — complete
  narrative, method, failures, and promotion boundary.

## Provenance and sanitization

The record was produced from authenticated exact-build gateway, controller,
Hermes, A2A, artifact, decoder, and managed-lifecycle observations. It names
display labels only. Private addresses, endpoint URLs, credentials, personal
paths, raw prompts, job identifiers, artifact identifiers, logs, and runtime
databases are omitted.

The generated PNG/MP4 files and contact sheet were transient validation
artifacts. They are not checked in because public evidence policy excludes
binary artifacts without an approved immutable external home. The JSON retains
their byte sizes, SHA-256 digests, format/decode facts, and the separately
administered adversarial review dispositions. This preserves the review record
but does not make the pixels publicly re-inspectable; the dated finding states
that limitation explicitly.

The isolated candidate services and credential-bearing runtime directories
were removed after verification. The managed ComfyUI model volumes and pinned
assets remain operator-owned and were not deleted.
