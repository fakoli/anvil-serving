The 32K profile was below Hermes's 64,000-token minimum. The separate 64K profile resolved 65,536 KV tokens and passed a quality request with 62,455 actual prompt tokens. These are bounded long-context observations, not proof of the maximum stable prompt. Short-input speed was approximately unchanged from the 32K profile. The historical GGUF control used less GPU memory; this promotion is a capability/speed tradeoff, not a footprint win.

An initial preflight omitted the profile overrides and requested 128K input and a 20-request burst. The resulting context-limit and queue-limit failures remain in the bundle. The corrected 60K nominal needle and C1 checks passed. Capacity used 32 exact output words, unique prompts, and no request canaries. The small sample counts do not establish tail latency; the 64K cells do not establish a new causal MTP speedup.

A planning draft incorrectly treated the 32K runtime allocation as pure KV. The 64K startup reports 3.39 GiB aggregate runtime allocation; no linear scaling claim is made. Startup whole-GPU use was 24,222 MiB and post-workload use 24,224 MiB. The reported total/used/free values leave 419 MiB unaccounted; this is arithmetic from rounded GPU telemetry, not an independently measured driver allocation.

The router, Workbench, Grafana, Hermes catalogs and Open WebUI now reflect the 64K model. Fleet repeat reconciliation made zero changes across three hosts and both active WebUI users. The separate Windows Pi catalog also converged. Pi/OpenClaw retain their explicit secondary omission to preserve the primary model's 65,536-token compaction reserve. Media generation remains withdrawn while Qwen owns the GPU. Native Hermes acceptance used the configured `anvil` provider; attempts through an older alternate credential fell back to cloud and are excluded from acceptance.

The exact OCI image is cached locally. Pinned build inputs are retained, but a fresh-host identical digest is not claimed. The original 32K managed recipe remains the rollback source; its launch metadata is immutable historical evidence.
