# Coverage and gaps

## Covered

- Final matched 327K local, fixed 60-case text/reasoning comparison with the same input
  corpus, request controls, parser, and local output cap.
- Complete-score, length-limit, summed sequential C1 request-time, completion-token, and
  paired-discordance summaries for both GLM profiles.
- AZ327 bounded retrieval (~128K), shared-prefix tools (20/20), and image cases
  (12/12 with Mia's exact template).
- One-card Qwen direct functional receipt and exact 0/8 eligibility boundary.
- Sanitized configuration and restoration receipts.

## Not covered

- A statistically supported accuracy difference, broad quality ranking, or
  external-publisher replication.
- Decode throughput, sustained concurrency, time to solve an interactive task,
  or long-context/capacity behavior. The separate matched 327K/C4 summary does
  not establish a broad concurrent-speed improvement.
- Broad AZ vision compatibility: AZ327 passed only the bounded image cases using
  Mia's exact template; the separate AZ64 native-template profile failed before
  generation.
- Qwen has bounded R3 multimodal (12/12) and agentic (3/3) receipts, plus a
  partial 12-item publisher pilot; it still has no eligible QAD C1/C4 timing
  population, capacity qualification, or comparable cross-runtime ranking.
- A matched C4 observation exists for AZ327/Mia and separately for Swift/Mia,
  but each is only an eight-request pair and neither supports a broad concurrent
  speed or capacity conclusion.
- Client, router, lifecycle, or promotion acceptance.
