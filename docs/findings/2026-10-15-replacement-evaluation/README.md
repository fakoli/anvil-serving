This bundle preserves native evidence for the retained GLM control and three
challengers on RTX PRO 6000 Blackwell Max-Q hardware. It does not establish a
universal model ranking.

The `native/` artifacts retain their original schemas, request/attempt results,
finish reasons and limits. Private endpoints, machine identity, operational
paths and reasoning text were removed; hashes of protected originals and
sanitation transformations are retained separately. Missing finalist tests
remain explicit in the summary. Configured limits are not measured capacity.

No eligible matched performance population reached finalist comparison, so no
throughput chart or speed ranking is produced. No compact external publication
copy was requested.
