# RTX 5090 benchmark view

**Hardware:** NVIDIA GeForce RTX 5090, 32,607 MiB, sm_120. **Host:** Fakoli
Dark, Windows 11 with Docker Desktop/WSL2. **Reviewed:** 2026-07-28.

## Current topology and services

The card has two operator-selectable shapes:

1. an exclusive [Nemotron Nano Omni 30B](../models/nemotron-omni-30b.md) stack
   for auxiliary text, general vision, and OCR; or
2. [Qwen2.5-Omni 3B](../models/qwen25-omni-3b.md) co-resident with dedicated
   [Parakeet STT](../models/parakeet.md) and [Kokoro TTS](../models/kokoro.md).

Embeddings/reranking and ComfyUI remain separately admitted stacks. The PRO
6000 Primary may remain running during these tests, but that makes it
`protected/co-resident`, not measured.

## Current and challenger state

| Capability | Model | Decision | Boundary |
|---|---|---|---|
| Auxiliary text, vision, OCR | [Nemotron Nano Omni 30B](../models/nemotron-omni-30b.md) | `current` topology | Audio input not qualified |
| Smaller co-resident Omni | [Qwen2.5-Omni 3B](../models/qwen25-omni-3b.md) | `challenger`, `no-promotion` | Text/image/OCR passed; audio was noisy |
| STT | [Parakeet TDT 0.6B v3](../models/parakeet.md) | `current` | Routed default |
| STT | [Qwen3-ASR 0.6B](../models/qwen3-asr.md) | `challenger`, `no-promotion` | Non-inferior WER margin; not routed |
| STT | [Nemotron 3.5 ASR](../models/nemotron35-asr.md) | `rejected` | WER regression exceeded margin |
| TTS | [Kokoro](../models/kokoro.md) | `current` | Co-resident voice component |
